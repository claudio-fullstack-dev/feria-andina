# Feria Andina

Repositorio del proyecto **Feria Andina** (Cardón Software).

## Estructura

- `web/`: Frontend (React + TypeScript + Redux Toolkit)
- `api/`: Backend (Node + Express + PostgreSQL)
- `docs/`: Documentación y comparativas de herramientas de IA
- `AGENTS.md`: Reglas generales del proyecto para agentes de IA
- `.github/copilot-instructions.md`: Instrucciones equivalentes para GitHub Copilot

## Ramas del Módulo 1
- `main`: configuración base del repositorio (Paso 1) y documentación comparativa.
- `feat/antigravity`: implementación de `calcularTotal` realizada con Antigravity.
