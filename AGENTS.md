# Feria Andina · instrucciones para agentes de IA

## Stack
- Front: React + TypeScript + Redux Toolkit (`/web`)
- Back: Node + Express + PostgreSQL (`/api`)

## Comandos
- Front (`/web`):
  - `npm test`: ejecuta la suite de tests con Vitest (`vitest run`).
  - `npm run typecheck`: valida TypeScript estricto (`tsc --noEmit`).
- Back (`/api`):
  - Pendiente de configuración inicial.

## Convenciones
- TypeScript estricto: no usar `any`.
- Nombres del dominio en español.
- Commits con Conventional Commits.

## No hacer
- No agregar dependencias nuevas sin avisar.
- No leer ni modificar archivos `.env`.
